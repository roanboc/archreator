archreator

Model your business, then let AI build it.

archreator is a free, open-source method that turns what you know about your business into an architecture an AI agent can build from — with you approving at every gate, in plain markdown, in your own repository.

Get started Get it on GitHub See it in use

Why it exists

Building software was hard, and slow. That was the visible problem, and it covered for everything behind it — requirements nobody had pinned down, business context that lived in one person's head. AI took that delay away faster than anyone planned for, and what it was covering is now the whole problem: vague requirements and missing context no longer slow a project down, they get built. Understanding the problem, and which solution actually fits it, is the part that stays human.

So the thing worth building now is not a faster way to produce software. It is a way to get your own assumptions written down where people can disagree with them, early, while disagreeing is still cheap.

archreator makes the understanding the deliverable. Before any code is written, the strategy, the business, the information, and the design are aligned in a shape both a human and an agent can read. You approve at three named gates. The agent picks up from there.

Two ways in, one model

The independent builder

Explain the business. Get only the architecture you need. The agent asks what your project is and takes it from there — you are never asked to learn a notation to answer a question about your own business.

The enterprise architect

Navigate the structure directly. Follow every relationship. The model is a standard layered structure in plain files, in the order you already know, with nothing between you and it.

One source serves both. An agent is helpful, never the only doorway.

What you get

  • Three gates, named for what you approve — Direction, Understanding, Design. A single application meets one of them, and one offer. There is no form to fill in for a gate that never applied.
  • Eighteen skills that make an AI agent follow the method faithfully, from starting a new project to writing the pull request.
  • Eleven files on your first commit, and every one of them is used. No empty folders standing in for a plan: your model's front page says, per layer, whether it is here, somewhere else, out of scope, or a gap.
  • AI actors as first-class citizens — every actor in your model carries a kind (human, AI, or hybrid) and every AI carries an autonomy level, decision rights, and an escalation path.
  • Nothing to operate — no database, no server, no cache to rebuild. Markdown in git is the model, and every tool reads it fresh.

Get started

archreator ships as a plugin for Claude Code, GitHub Copilot and Codex, and as skills for Gemini CLI. In Claude Code that is two slash commands: 

/plugin marketplace add roanboc/archreator
/plugin install archreator@archreator

Then just say what you want to model. The establish-project skill takes it from there — it asks what the project is, picks a modeling depth, and writes eleven files into your repository.
