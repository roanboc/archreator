archreator

Model your business, then let AI build it.

archreator is a free, open-source method that turns what you know about your business into an architecture an AI agent can build from — with you approving at every gate, in plain markdown, in your own repository.

Get it on GitHub See it in use

Why it exists

AI can now build almost anything you can describe. What it cannot do is know what you meant. Most software fails not because the code was hard but because the problem was misunderstood — and AI amplifies that, confidently, at speed.

archreator makes the understanding the deliverable. Before any code is written, the strategy, the business, the information, and the design are aligned in a shape both a human and an agent can read. The human approves at explicit gates. The agent picks up from there.

What you get

  • A methodology that walks your requirement through six architecture layers — strategy first, technology last — with human approval built into the flow.
  • Fifteen skills that make an AI agent follow the method faithfully, from bootstrapping a new project to writing the pull request.
  • An empty scaffold your project starts from, with layer READMEs, validators, and PR templates ready to go.
  • AI actors as first-class citizens — every actor in your model carries a kind (human, AI, or hybrid) and every AI carries an autonomy level, decision rights, and an escalation path.

Get started

archreator ships as a Claude Code plugin. Inside any Claude Code session: 

/plugin marketplace add roanboc/archreator
/plugin install archreator@archreator

Then just say what you want to model. The establish-project skill takes it from there.

Two repositories

  • archreator — the method: the skills, the scaffold, the plugin package. What ships to your project.
  • architecture-archreator — worked models: archreator applied to a real organization and to itself, so you can see what a filled-in model looks like.
