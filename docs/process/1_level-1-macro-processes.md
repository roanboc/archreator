# ArChreator macro processes — Level 1

_[Process model](./README.md) · [The method](../method.md) · [Repository README](../../README.md)_

**Location:** ArChreator method → Process model → Level 1.

These three macro processes state why the method's work exists. Their children
are defined in the [Level 2 process file](./2_level-2-processes.md).

| ID | Name | ArchiMate type | Description | Composed of |
| --- | --- | --- | --- | --- |
| BPROC1 | Model connected current context | Business Process | Establishes the smallest reliable description of what exists and connects another model only when a real need crosses a boundary. | Model current context [BPROC1.1]; Connect cross-model context [BPROC1.2] |
| BPROC2 | Use context to understand and plan | Business Process | Turns current context into a grounded answer or an actionable direction. | Answer a context question [BPROC2.1]; Plan a roadmap [BPROC2.2] |
| BPROC3 | Deliver change and keep context true | Business Process | Assesses, implements and verifies a change, then reconciles the canonical model. | Frame and assess a change [BPROC3.1]; Implement and verify [BPROC3.2]; Refresh current context [BPROC3.3] |
